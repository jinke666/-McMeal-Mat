# 🍔 麦麦搭子 McMeal-Mate

面向麦当劳消费场景的低摩擦 AI 点餐助手（Skill）。基于麦当劳官方 MCP 与多约束运筹优化算法，提供高确定性首选推荐、个性化偏好记忆与多人费用公平分摊。

> **核心原则：少问问题，给出清晰推荐；记住明确偏好，涉及关键操作先确认。**

---

## 核心特性

- **低摩擦自然语言点餐**：从日常单句表达中一次性提取预算、人数、忌口与偏好，默认输出单一最优解及简要决策理由；支持“贵了 / 换一个”等短反馈的局部增量微调，不重置上下文。
- **多人协同与公平分摊**：隔离团队成员个性化忌口与口味，自动优选共享餐品；基于个人基准消费权重执行数学级公平分摊，输出精确到角分的 AA 账单。
- **严格数据可信标准**：建立严密的凭证分级体系，严格区分 `LIVE_VERIFIED`（官方接口核价）、`ESTIMATED`（本地测算）、`CACHED`（缓存数据）与 `MOCK`（离线演示），绝不伪造价格与门店。
- **隐私可控的长期记忆**：基于轻量级 SQLite 持久化，显式区分“用户主动告知”与“系统推断”；支持记忆透明查阅与一键清除，保障用户遗忘权。
- **副作用安全门禁**：查询与优化计算完全只读执行；领券、下单、取消等可能改变账户状态或产生费用的动作，必须获得用户单次明确授权。

## 快速开始

### 方式一：WorkBuddy 智能体（推荐，免配置）

无需克隆源码或配置 Python 环境，直接下载 Skill 导入 WorkBuddy 即可使用：

1. **[下载麦麦搭子 Skill 安装包（ZIP）](https://github.com/jinke666/-McMeal-Mat/raw/refs/heads/main/dist/mcmeal-mate-skill.zip)**（或直接获取 [SKILL.md](https://raw.githubusercontent.com/jinke666/-McMeal-Mat/main/SKILL.md)）
2. 在 WorkBuddy【技能/Skill】中导入该文件并启用。
3. 试着对麦麦说：
   - *“帮我选一份 30 元以内、不辣的鸡肉午餐。”*
   - *“我和朋友一起吃，一个不吃辣，帮我们搭配一下。”*
   - *“这个有点贵，换个更划算的。”*

> *注：如需查询实时门店、菜单、优惠与真实价格，需在 WorkBuddy 中配置麦当劳官方 MCP 连接器，详见 [WorkBuddy 集成指南](workbuddy.md)。*

### 方式二：开发者本地运行

用于调试运筹优化算法、本地记忆模块或 MCP 客户端适配：

```bash
git clone https://github.com/jinke666/-McMeal-Mat.git mcmeal-mate
cd mcmeal-mate
python -m pip install -e .

# 运行全场景演示脚本
python scripts/demo.py

# 运行自动化测试套件
python -m unittest discover tests -v
```

## 项目结构

| 模块 / 路径 | 说明 |
| :--- | :--- |
| `SKILL.md` | Agent Skill 规范定义与低摩擦交互规则（唯一真理源） |

| `dist/` | 构建发布的免配置独立 Skill ZIP 安装包 |
| `MCP_INTEGRATION.md` | 麦当劳官方 MCP 协议适配与可信度分级说明 |
| `workbuddy.md` | 腾讯 WorkBuddy 连接器配置与验收用例 |

## 能力与合规边界

- **实时数据依赖**：实时菜单、在售状态与真实结算价格依赖麦当劳官方 MCP 接口的在线响应。未连接或接口调用失败时，系统自动降级并标记为 `MOCK` 或 `ESTIMATED`，不代表实时报价。
- **支付闭环声明**：本项目聚焦点餐决策推荐与接口适配，不包含未授权的自动支付通道，涉及支付与实际出单以麦当劳官方客户端为准。
- **独立开源声明**：本项目为参赛独立开发项目，麦当劳相关商标及官方服务归其各自权利人所有。
