# 🍔 麦麦搭子 McMeal-Mate

**把点餐的复杂事交给麦麦，把简单留给你。**

麦麦搭子是一个面向麦当劳场景的 AI 点餐 Skill。告诉麦麦你的预算、口味和忌口，它会帮你整理需求、搭配餐品；和朋友一起吃，也能考虑双方偏好与费用分摊。

> 💬 “帮我和朋友点一份 60 元以内的午餐，一个不吃辣，一个想吃鸡肉。”
>
> 剩下的，让麦麦来想。

## ✨ 麦麦能做什么？

- 🍟 **听懂你的点餐需求**：从自然语言中提取预算、人数、口味和忌口，尽量少追问，优先给出清晰首选。
- 🧠 **记住你明确说过的偏好**：通过本地记忆模块保存偏好，并支持查看和清除。
- 🧮 **帮你搭配餐品**：按预算等条件组合餐品，支持多人方案与费用分摊计算。
- 🔎 **对接菜单与优惠查询**：通过 MCP 接口封装查询门店、菜单、活动和价格；是否实时可用取决于连接配置。
- 🛡️ **重要操作先确认**：查询和计算可以按需求进行；领券、下单、取消等操作需要明确授权。

> 🔌 想查实时门店、菜单、优惠或价格？还需要在 WorkBuddy 中配置可用的麦当劳 MCP 连接器。

## 🧩 项目一览

| 模块 | 用途 |
| --- | --- |
| `SKILL.md` | 麦麦的交互规则与工作流程 |
| `mcmeal/` | 本地配餐优化、记忆等逻辑 |
| `tests/` | 自动化测试 |
| `scripts/` | 本地演示与辅助脚本 |
| `MCP_INTEGRATION.md` | MCP 配置与集成说明 |

开发者想运行本地演示，可以从源码开始：

```bash
git clone https://github.com/jinke666/-McMeal-Mat.git mcmeal-mate
cd mcmeal-mate
python -m pip install -e .
python scripts/demo.py
```

## ℹ️ 关于实时能力

- 实时菜单、优惠和价格取决于 MCP 服务是否成功连接，以及服务返回的数据。
- 未连接或调用失败时，演示数据和估算结果不代表实时报价。
- 当前项目不代表已经打通完整的官方下单与支付流程。
