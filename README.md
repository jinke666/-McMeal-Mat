## 📖 项目简介 (Introduction)

点餐本来不该是一场复杂的计算。麦麦搭子的目标，是把预算、口味、忌口和优惠等条件交给助手处理，让用户用更少的对话选到合适的一餐。

**麦麦搭子（McMeal-Mate）** 是一个面向麦当劳点餐场景的 AI 助手项目，结合自然语言需求整理、本地配餐优化、SQLite 偏好记忆和 MCP 客户端封装。它强调三个原则：**少问不必要的问题、默认给出一个清晰首选、对价格和工具能力诚实**。

当前仓库包含可运行的本地优化逻辑、记忆模块、MCP 接口封装及单元测试。真实门店、菜单、优惠和价格是否可用，取决于有效的 MCP 凭证、服务端当前工具及响应格式；离线演示数据不代表真实在售或可下单。项目目前不应被描述为已经打通完整的官方下单、支付闭环。

## ✨ 核心能力与当前边界 (Capabilities & Limits)

- 💬 **低摩擦点餐交互**：
  - 尽量从一句话提取预算、口味、人数和忌口；
  - 默认优先给一个首选方案，避免不必要的多方案长报告；
  - 对“贵了”“换一个”等反馈只修改相关条件，保留其他已确认信息。
- 🧠 **本地偏好记忆**：
  - 使用 SQLite 保存偏好与相关记录，支持查看和清除；
  - 明确区分用户主动表达与系统推测，不把一次性订单条件自动当作长期偏好；
  - 是否能跨设备或跨宿主持续记忆，取决于部署方式，不能仅凭本地模块推断。
- 🧮 **本地配餐优化**：
  - 根据预算、热量等约束对候选餐品进行组合优化；
  - 支持多人方案和共享餐品分摊的本地计算；
  - 本地计算结果不等同于官方最终结算金额。
- 🔌 **MCP 客户端封装**：
  - 包含门店、菜单、活动、优惠及核价等接口封装；
  - 只有成功调用并可靠解析的当前响应，才能标记为实时核验；
  - 无凭证、调用失败或响应结构无法识别时，应明确降级为模拟或估算数据。
- 🛡️ **授权优先**：
  - 查询与计算等只读操作可在用户需求范围内执行；
  - 领券、兑换权益、下单、取消和支付等有副作用的操作，不得在没有明确授权时自动执行；
  - 当前仓库不应被理解为已经具备完整的真实下单与支付实现。

## 🛠️ 系统架构与 Skill 设计 (Architecture)

麦麦搭子将 Agent 交互、本地优化与 MCP 接口封装分层组织；真实在线能力需在有效凭证和当前工具 Schema 下联调验证：

```mermaid
flowchart LR
    User([用户自然语言意图 / 双人拼单]) --> Skill["麦麦 Skill 交互层\n(人设表达 / 口味解析 / 记忆持久化)"]
    Skill --> Engine["运筹求解引擎\n(双人协同 / 背包优化 / 公平分摊)"]
    Engine <--> MCP["麦当劳官方 MCP 服务\n(活动日历 / 菜单与优惠查询 / 核价 / 授权后的账户操作)"]
    Engine --> Output([双人方案与公平 AA 账单])
```

- **Skill 交互层 (`SKILL.md`)**：定义“自然、有判断、少打扰”的麦麦人设、低摩擦对话规则、动作确认门禁；SQLite3 长期偏好记忆区分用户明确告知与系统推测，支持查看和清除；
- **运筹求解引擎 (`mcmeal/`)**：实现多约束背包剪枝、独立餐品忌口隔离与数学级公平分摊模型；
- **MCP 服务桥接 (`https://mcp.mcd.cn`)**：对接时间日历、菜单、优惠查询与 `calculate-price` 核价；副作用操作由授权门禁控制，不把模拟/降级结果冒充实时数据。

## 🧭 交互原则：把复杂留给麦麦

- **一句话优先完成**：自动提取预算、人数、口味、忌口与餐品要求；信息足够时直接查询并推荐，不为补齐非必要字段打断用户。
- **默认一个首选**：先给一个当前数据支持的方案和价格，必要时附一个备选；不默认输出三套长报告。
- **短反馈可迭代**：“贵了”“换一个”“别要可乐”只调整对应条件，其他已确认信息保持不变。
- **只读操作优先自动完成**：查菜单、优惠、价格和优化候选可在用户请求范围内自动进行；领券、积分兑换、下单、取消订单等有副作用的动作必须先明确授权/确认。
- **真实性优先**：离线/模拟数据必须清楚标记；未穷尽当前候选前，不声称“全场最低价”。

## 🚀 快速使用：不需要懂代码

如果你只是想在 WorkBuddy 里使用麦麦，**不需要克隆仓库、不需要安装 Python，也不需要运行命令**。本项目的日常使用入口是 Skill；下面的代码运行方式只适合开发者。

### 方式一：下载 Skill（推荐）

1. 下载 [麦麦搭子 Skill 文件（SKILL.md）](https://raw.githubusercontent.com/jinke666/-McMeal-Mat/main/SKILL.md)。
2. 打开 WorkBuddy 的 Skill 管理/导入入口，选择本地文件并导入这个 `SKILL.md`。如果你的 WorkBuddy 版本只支持文件夹或 ZIP 导入，请使用下方的 Skill 包；如果界面没有导入入口，再参考 WorkBuddy 当前版本的官方说明。
3. 在 WorkBuddy 中启用“麦麦搭子”，直接说“帮我点一份 30 元以内、不辣的鸡肉午餐”即可试用。
4. 如需查询真实门店、菜单、优惠或价格，再按 WorkBuddy 的 MCP 连接器说明配置麦当劳 MCP。没有配置连接器时，不能把推荐当成实时菜单或实时报价。

> **注意**：Skill 是行为说明与工作流规则，不会凭空获得麦当劳账户权限。真实 MCP 查询能力取决于连接器配置；本仓库也不代表已经实现完整的官方下单/支付闭环。

### 方式二：下载独立 Skill ZIP（更方便）

仓库会自动打包一个只包含 Skill 和安装说明的 ZIP，不需要下载整套 Python 项目：

1. 打开 [麦麦 Skill 打包任务](https://github.com/jinke666/-McMeal-Mat/actions/workflows/package-skill.yml)。
2. 进入最新一次成功的运行记录，在页面底部的 **Artifacts** 区域下载 `mcmeal-mate-skill`。
3. 解压后，将里面的 `SKILL.md` 导入 WorkBuddy 并启用。

这个 ZIP 是独立 Skill 包；麦当劳 MCP 连接器仍需按你的 WorkBuddy 环境单独配置。若打包任务还在运行，请稍等它完成后再下载。

### 方式三：开发者本地运行（可选）

只有你想运行本地算法、记忆模块或调试 MCP 客户端时，才需要以下步骤。

```bash
git clone https://github.com/jinke666/-McMeal-Mat.git mcmeal-mate
cd mcmeal-mate
python -m pip install -e .
python scripts/demo.py
```

查看或清除本地记忆：

```bash
python -m mcmeal.cli --view-memory
python -m mcmeal.cli --clear-memory
```
