# 🍔 麦麦搭子 McMeal-Mate

你的专属麦当劳 AI 点餐搭子！🍟✨  
基于麦当劳官方 MCP 服务与运筹学多约束优化算法，专注“低摩擦”极速点餐：带图推荐更直观、贴心记住去冰/忌口备注、多人聚餐公平 AA 分摊，把复杂省钱留给算法，把美味轻松留给你！😋

> **💡 核心原则：少问一句废话，给出一套好方案；记住你的习惯，关键操作严格确认。**

## ✨ 核心特性

- 🗣️ **低摩擦自然语言点餐**：一句话说明预算、人数或口味，麦麦直接给出最优首选 + 秒懂理由；支持“太贵了 / 换一个 / 不要辣”等日常口语化直接微调，不用重新填表！
- 📝 **贴心制作备注与忌口排查**：主动识别辣味、海鲜、牛奶等敏感属性，全方位支持麦当劳标准客制化备注（可乐去冰/少冰、汉堡去酸黄瓜/去洋葱/去酱等），还会悄悄记在脑子里～
- 🖼️ **官方高清餐品图直观呈现**：打通麦当劳官方 CDN 图片库，推荐清单直接渲染高清实物图（终端模式附直达链接），餐品长啥样、分量搭不搭配一目了然！
- 👥 **聚餐协同与数学级公平分摊**：一人点餐众口难调？麦麦自动隔离不同忌口、优选共享小食拼盘，并用严谨的数学模型按原价消费比重精准分摊，生成的 AA 账单精确到分！
- 🛡️ **数据真实绝不画饼**：建立严谨的凭证分级体系，严格区分 `LIVE_VERIFIED`（官方接口实时验价）、`ESTIMATED`（运筹测算）与 `MOCK`（离线演示），绝不编造虚假优惠与门店。
- 🧠 **透明可控的长期记忆**：轻量 SQLite 本地存储，分清“你明确交代的”与“麦麦推测的”；支持随时查阅偏好画像与一键遗忘，隐私完全由你掌控。
- 🔒 **关键操作安全门禁**：领券、下单、取消等涉及账户资产的动作绝不自作主张，必须取得你的一次明确确认，安全感拉满！

## 🚀 快速开始

### 方式一：WorkBuddy 智能体（推荐，开箱即用 ⚡）

无需克隆源码或配置 Python 环境，直接下载 Skill 导入腾讯 WorkBuddy 即可使用：

1. 📦 **[下载麦麦搭子 Skill 安装包（ZIP）](https://github.com/jinke666/-McMeal-Mat/raw/refs/heads/main/dist/mcmeal-mate-skill.zip)**（或直接获取 [SKILL.md](https://raw.githubusercontent.com/jinke666/-McMeal-Mat/main/SKILL.md)）
2. 🔌 在 WorkBuddy【技能 / Skill】中导入该文件并启用。
3. 💬 试着对麦麦说两句：
   - *“预算 30 元想吃汉堡和饮料，可乐去冰，汉堡不要酸黄瓜。”*
   - *“帮我选一份 30 元以内、不辣的鸡肉高蛋白午餐。”*
   - *“我和朋友一起吃，一个不吃辣，帮我们搭配一下。”*
   - *“这个有点贵，换个更划算的。”*

> 📌 *注：如需查询实时门店、菜单、优惠与真实价格，需在 WorkBuddy 中配置麦当劳官方 MCP 连接器，详见 [WorkBuddy 集成指南](workbuddy.md)。*

### 方式二：开发者本地运行 💻

用于调试运筹优化算法、本地记忆模块或 MCP 客户端适配：

```bash
git clone https://github.com/jinke666/-McMeal-Mat.git mcmeal-mate
cd mcmeal-mate
python -m pip install -e .

# 🏃 运行全场景演示脚本（极限省钱、控卡高蛋白、39元免配拼单、双人AA分摊）
python scripts/demo.py

# 🍔 运行命令行交互式点餐（支持自然语言、预算、制作备注）
python -m mcmeal.cli -p "预算30想吃汉堡和饮料，可乐去冰"

# 🧪 运行自动化测试套件（21 项单元与安全门禁测试）
python -m unittest discover tests -v
```
