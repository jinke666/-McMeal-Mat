# 技术决策记录

> 只记录团队已确认的决策。建议方案不能自动视为已通过决策。

## D-001：GitHub 作为共同代码底座
- 状态：建议采用，待团队确认
- 背景：WorkBuddy 项目功能目前出现“网络异常，项目暂时无法加载”。
- 决策建议：代码、项目背景、任务清单和重要技术决策保存在 GitHub 仓库，降低对单一 AI 平台的依赖。
- 影响：两位开发者需要遵守分支、提交和合并约定。
- 风险：GitHub 不能自动同步某个 AI 工具的聊天记录；本地未提交内容仍需单独备份。

## D-002：项目记忆以版本化文档保存
- 状态：建议采用，待团队确认
- 决策建议：使用 `AGENTS.md`、`TASKS.md`、`docs/PROJECT_BACKGROUND.md`、`docs/DECISIONS.md` 和 `docs/DEVELOPMENT_LOG.md`。
- 影响：不同 AI 工具可读取同一套项目背景；每次任务后需更新状态。

## D-003：MCP 能力以官方资料和实测为准
- 状态：原则已提出，具体工具待核验
- 决策建议：不凭空假设接口、参数或下单能力。重要能力需记录文档依据、调用结果和测试日期。
